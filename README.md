# make-knowledge-cards

一个 Agent Skill：把一篇文章转换成 5–8 张知识卡片。

## 1. 项目解决什么问题

读完一篇长文后，想复习时往往只剩一份长摘要：知识点挤在一起，分不清哪些真正重要，也不好逐条自测。手工做卡片则要反复判断“这张卡该切多细”“这句话是不是原文说的”，耗时且容易走样。

这个 Skill 把这件事变成一套固定流程：先筛出重要的、互不重复的知识点，再一张卡讲一个点，最后逐条核对有没有超出原文。产出的卡片可以直接用来背记、自测，或作为笔记的最小单位。

## 2. 主要功能

- **生成 5–8 张知识卡片**：每张包含标题、核心知识、简明解释、例子或自测问题四项。
- **只提取重要知识**：按定义、机制、因果、数据与标准、步骤、适用条件、常见误区、结论筛选，删掉重复和换说法的内容。
- **一张卡只讲一个知识点**：标题写成可判断真假的陈述句；解释中出现“另外 / 同时”引出第二个独立结论时会拆卡。
- **按文章类型调整**：科普文重机制和边界，教程按步骤并说明做错的后果，观点文保留作者归属，新闻合并同类参数，清单文合并同类条目。
- **不编造**：只使用原文信息，数字、单位、条件原样保留；不补原文没有的原因、影响和评价；原文没有例子时出自测题，答案必须能在原文找到。
- **信息不足不凑数**：独立知识点不到 5 个就少出，并在开头说明原因。
- **可保存为文件**：用户要求时写出 `<源文件名>-知识卡片.md`。

暂不支持：网页抓取、PDF、Word、Anki 导出、图形界面。输入只接受粘贴文本或本地 `.md` / `.txt` 文件。

## 3. 安装方法

这个 Skill 只有说明文件，没有脚本和第三方依赖。

1. 下载或克隆本项目。
2. 把 `skills/make-knowledge-cards` 整个目录复制到所用 Agent 的 skills 目录，例如：

```text
<agent-workspace>/.skills/make-knowledge-cards/
├── SKILL.md
├── agents/openai.yaml
└── references/examples.md
```

3. 重新加载 Skill 列表，确认能看到 `make-knowledge-cards`。

要求 Agent 支持读取 `SKILL.md` 的 Skill 机制；不同客户端的 skills 目录位置可能不同，以该客户端文档为准。

## 4. 使用方法

用下面任意一种方式给输入，并说明要做知识卡片：

- **粘贴文章**：把正文直接发给 Agent，加一句“整理成知识卡片”。
- **本地文件**：给出 `.md` 或 `.txt` 的路径，加一句“把这个文件做成卡片”。

可用的触发说法包括：“做成知识卡片”“提炼知识点”“拆成学习卡片”“生成复习卡片”“做卡片笔记”。

默认在对话中输出 Markdown 卡片。需要落盘时补一句“保存成文件”，会在源文件同目录生成 `<源文件名>-知识卡片.md`；粘贴文本则生成 `知识卡片-<主题>.md`。

如果文章超过 8 个独立知识点，只保留最重要的 8 个；少于 5 个时按实际数量输出，并在开头注明“原文可提炼 N 个独立知识点，未凑满 5 张”。

## 5. 输入输出示例

**输入**（`深度学习科普.txt`，本项目自写的示例段落）：

> 一个人工神经元会接收多个输入 x。不同输入的重要性并不相同，所以每个 x 都配一个权重 w：越重要的输入配越大的 w，再把所有乘积相加。接下来要过一道门槛：给总和减去阈值 b，只有结果大于零，信号才继续向后传递，否则输出零。这道决定信号能否通过的门槛由激活函数实现，常见例子是 ReLU。由于前面全是线性运算，激活函数通常取非线性的，网络才能表达复杂的非线性关系。

**输出**：

```markdown
### 卡片 1：神经元用权重表示输入的重要性，再由激活函数决定是否通过

- **核心知识**：每个输入 x 乘以权重 w，重要的信号乘大 w、不重要的乘小 w，乘积求和后减去阈值 b，差值大于零才通过，否则输出零。
- **简明解释**：权重让重要信号在总和中占更大比重；减去阈值后再判断是否大于零，相当于给信号设了一道通过门槛。这道门槛由激活函数实现，文中举的是 ReLU；因为前面的运算都是线性的，激活函数一般取非线性的。
- **原文依据**：“给总和减去阈值 b，只有结果大于零，信号才继续向后传递，否则输出零。”
- **例子 / 自测**：某个输入对判断结果很重要，它的权重应该取大一些还是小一些？
```

示例段落只含一个知识点，因此只生成一张卡；换成整篇文章时，同一套流程会输出 5–8 张卡。

用于验证的 5 类文章（科普、教程、观点、新闻、短文本）均按实际知识点数量产出卡片；`SKILL.md` 已通过 `quick_validate.py` 校验。
